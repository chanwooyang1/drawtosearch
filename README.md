# drawtosearch

Starter repository for the `drawtosearch` project.

## Getting started

1. Add your project files.
2. Review and update `.gitignore` if your stack needs extra rules.
3. Create the first commit and connect a GitHub remote.

## GitHub remote

After you create a GitHub repository, connect it with:

```bash
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```
